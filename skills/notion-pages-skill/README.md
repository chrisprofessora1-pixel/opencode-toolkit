# 📓 notion-pages Skill (v2 — merged)

A skill for building advanced, aesthetic, and efficient Notion pages, templates,
and systems — with a special focus on **homework pages for language teachers**.

This version merges the original notion-pages skill (design systems, database
architecture, formulas, automations, template archetypes) with the teacher's
homework brain (63-exercise catalog, level bands, formatting rules) and the
**verified block recipe** extracted from a real homework page ("August 7 -
Homework").

---

## What This Skill Does

| Template Type | What It Covers |
|---|---|
| 🏠 Dashboard | Multi-column home page, widgets, filtered linked DBs, persistent nav |
| 🗺️ Roadmap | Timeline view, priority formulas, Epic grouping, schedule risk |
| 📋 Kanban Board | Status columns, WIP limits, Scrum vs Kanban patterns |
| 🧠 Life OS / PARA | Projects, Areas, Resources, Archives + Quick Capture Inbox |
| 🎨 Design System | 6-section brand/component structure, embedded Figma |
| 📅 Content Calendar | Multi-platform publishing tracker with gallery view |
| 📊 Project Tracker | Relations to tasks, progress formula, client linking |
| 📝 Homework Page ★ | Exact verified block recipe (callouts, WORD BOX, numbered gaps, T/F with Correction, Mixed Gap Review) + content rules |

## Installation

### Option 1 — Install the `.skill` file
1. Download `notion-pages-skill.skill`
2. Open Claude settings → Skills
3. Drag and drop the `.skill` file to install

### Option 2 — Manual install
1. Open your skills folder (`~/.claude/skills/` or `.opencode/skills/`)
2. Create a new folder `notion-pages-skill/`
3. Copy `SKILL.md` into that folder
4. Restart
